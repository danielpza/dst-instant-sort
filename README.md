# DST - Instant Sort [![Static Badge](https://img.shields.io/badge/danielpza%2Fdst--instant--sort-_?style=flat-square&logo=github&label=Source%20Code&labelColor=gray&color=blue)](https://github.com/danielpza/dst-instant-sort) [![Steam Downloads](https://img.shields.io/steam/downloads/3793378886?style=flat-square&color=blue&label=steam%20downloads)](https://steamcommunity.com/sharedfiles/filedetails/?id=3793378886) [![Steam Subscriptions](https://img.shields.io/steam/subscriptions/3793378886?style=flat-square)](https://steamcommunity.com/sharedfiles/filedetails/?id=3793378886)

Client side only mod for Don't Starve Together.

Instantly sorts inventory and containers purely on the client side without any delay. Keeps inventory sorted at all times without sending any actions to the backend.

## Known Issues and workarounds

In some cases some keybindings might not work (numbers 1-10), to fix you need to go to the Don't Starve Together main game control settings and make sure the keybindings for input 11-15 are assigned!
